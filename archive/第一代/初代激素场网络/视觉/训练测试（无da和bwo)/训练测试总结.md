## 六、从 Checkpoint 提取诊断数据

### 方法 1: 使用提取脚本
```bash
python extract_diagnostics.py
```

### 方法 2: 手动提取
```python
import torch
from models.hormonicformer_v3 import HormonicFormer

# 加载 checkpoint
checkpoint = torch.load('checkpoints/best.pt')
model = HormonicFormer(**checkpoint['config'])
model.load_state_dict(checkpoint['model_state_dict'])

# 获取诊断数据
diag = model.get_diagnostics()
print(f"STP Efficacy: {diag['stp_efficacy_mean']:.4f}")
print(f"Homeo Gain: {diag['homeo_gain_mean']:.4f}")
print(f"G Sparsity: {diag['G_sparsity']:.2%}")
```
