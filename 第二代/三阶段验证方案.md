### 监控指标（每个 epoch 记录）
| 指标 | 初始值 | 正常范围 | 异常信号 |
|------|--------|----------|----------|
| limit_cycle_radius | ~1.0 | 0.5-2.0 | →0: CGL死亡 |
| DA | ~0.5 | 0.1-0.9 | 长期0.9: 网络不稳定 |
| CB | ~0.0 | 0.0-0.5 | 长期=0: 同步未触发 |
| STP_eff | ~1.0 | 0.3-1.5 | 持续↓: 突触疲劳 |
| G_sparsity | 0.0 | 0.0-0.3 | 恒=0: Hebbian未激活 |
| PC_loss | 高 | 逐渐↓ | 不下降: 预测回路失效 |
| 分类准确率 | ~10% | 逐渐↑ | 不上升: 整体失效 |

### 预期动态行为
```
Epoch 1-5:
  - limit_cycle_r: 稳定在 0.8-1.2
  - DA: 波动大（0.3-0.8），随loss起伏
  - CB: 缓慢上升（0→0.2）
  - STP_eff: 可能短暂下降（场变化率大）
  - G_sparsity: 开始产生非零值（<5%）
  - PC_loss: 明显下降

Epoch 6-15:

  - DA: 波动减小，趋于稳定
  - CB: 可能自限振荡（0.2→0.4→0.2）
  - STP_eff: 回升并稳定
  - G_sparsity: 稳定（5-15%）
  - PC_loss: 继续缓慢下降
  - 准确率: 50%→65%

Epoch 15-20:
  - 各指标趋于稳定
  - 准确率: 65-70%
```

## 阶段 2：序列任务验证（字符级 MLM）

### 数据准备
```python
# 使用 WikiText-2 前 100 万字符
from torchtext.datasets import WikiText2
import torch
from torch.utils.data import Dataset

class CharDataset(Dataset):
    def __init__(self, text, seq_len=128, mask_ratio=0.15):
        self.chars = sorted(list(set(text)))
        self.char2idx = {c: i for i, c in enumerate(self.chars)}
        self.idx2char = {i: c for c, i in self.char2idx.items()}
        self.vocab_size = len(self.chars)
        self.seq_len = seq_len
        self.mask_ratio = mask_ratio
        
        # 编码文本
        self.data = [self.char2idx[c] for c in text if c in self.char2idx]
        
    def __len__(self):
        return len(self.data) // self.seq_len
    
    def __getitem__(self, idx):
        chunk = self.data[idx*self.seq_len:(idx+1)*self.seq_len]
        x = torch.tensor(chunk[:-1])
        y = torch.tensor(chunk[1:])
        
        # 随机 mask
        mask = torch.rand(len(x)) < self.mask_ratio
        masked_x = x.clone()
        masked_x[mask] = self.char2idx['<mask>']  # 需要添加 mask token
        
        return masked_x, y, mask
```

## TensorBoard 记录代码

```python
from torch.utils.tensorboard import SummaryWriter
import os

log_dir = "runs/hormonic_v7r3_cifar10"
os.makedirs(log_dir, exist_ok=True)
writer = SummaryWriter(log_dir)

for epoch in range(num_epochs):
    for batch_idx, (data, target) in enumerate(train_loader):
        # 前向
        logits, loss = model(data, target)
        
        # 获取诊断
        diag = model.get_diagnostics()
        
        global_step = epoch * len(train_loader) + batch_idx
        
        # 记录标量
        writer.add_scalar('Loss/train', loss.item(), global_step)
        writer.add_scalar('DA/activity', diag['DA'], global_step)
        writer.add_scalar('CB/state', diag['CB'], global_step)
        writer.add_scalar('STP/efficacy', diag['STP_eff'], global_step)
        writer.add_scalar('CGL/limit_cycle_r', diag['limit_cycle_r'], global_step)
        writer.add_scalar('Hebbian/G_sparsity', diag['G_sparsity'], global_step)
        
        # 记录直方图
        if batch_idx % 50 == 0:
            writer.add_histogram('Hebbian/G_values', model.blocks[0].hebbian.G.data, global_step)
    
    # 验证准确率
    val_acc = evaluate(model, val_loader)
    writer.add_scalar('Accuracy/val', val_acc, epoch)

writer.close()
```
